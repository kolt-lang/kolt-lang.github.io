std test ​

A tiny test toolkit lives in the stdlib, with no extra dependency for basic checks. One rule first: the assertion methods throw on failure, so every toBe, toEqual, assert, and friends needs a try in front, and so does describe itself. Without it the result is will not propagate warnings.

kolt
import std "test"

try test.describe("math", fn() {
  test.test("adds", fn() {
    try test.expect(1 + 1).toBe(2)
    try test.expect(2).toEqual(2)
    try test.assert(true)
  })
})

const ok = test.summary()

Runner functions ​

describe(suiteName: string, action: fn(): any) ​

kolt
try test.describe("cart", fn() {
  test.test("totals", fn() {
    try test.expect(1 + 1).toBe(2)
  })
})

Groups output under a suite name. Bodies hold multiple statements, so they stay as fn blocks. describe propagates errors from its action, hence the leading try.

test(testName: string, action: fn(): any) ​

kolt
test.test("adds", fn() {
  try test.expect(1 + 1).toBe(2)
})

Runs one case, prints a check or a cross with the failure message. It catches assertion errors internally, so test(...) itself needs no try, only the asserts inside do.

assert(condition: bool, message: string = "Assertion failed") ​

kolt
try test.assert(user.age > 0, "age must be positive")

Throws on a false condition, so it always needs try.

summary(): bool ​

kolt
const ok = test.summary()

Prints the totals and returns true when everything passed. Never throws. Handy as a script exit signal.

expect<T>(val: T): Expectation<T> ​

kolt
try test.expect(1 + 1).toBe(2)

Starts a fluent expectation chain. expect alone never throws, but the chain ends in a throwing check, so the whole line gets try.

Expectation methods ​

not(): Expectation<T> ​

kolt
try test.expect(1).not().toBe(2)

not just flips the flag, but the terminal check still throws, so keep the try.

toBe(expected: T) ​

kolt
try test.expect(1 + 1).toBe(2)

toEqual(expected: any) ​

kolt
try test.expect(2).toEqual(2)

toBeNull() ​

kolt
try test.expect(missing).toBeNull()

toBeTrue() ​

kolt
try test.expect(ok).toBeTrue()

Strict bool only, 1 and "x" fail it.

toBeFalse() ​

kolt
try test.expect(done).toBeFalse()

Strict bool only, 0 and "" fail it.

toBeGreaterThan(expected: number) ​

kolt
try test.expect(score).toBeGreaterThan(90)

toBeLessThan(expected: number) ​

kolt
try test.expect(score).toBeLessThan(100)

toThrow() ​

kolt
try test.expect(() => risky()).toThrow()

Pass a closure and it asserts the call throws.
