Writing Native Extensions

Language Server (LSP)

On this page

std color ​

An extension string with ANSI styles. Import it and chain.

kolt
import std "color"
import std "io"

io.println("hi".bold().red())
io.println("warn".bgYellow().black())
if io.isTerminal() {
  io.println("fancy".rgb(255, 120, 0));
}
