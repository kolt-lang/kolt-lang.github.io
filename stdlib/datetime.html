std datetime ​

ISO 8601 calendar date and time representations with timezone support, formatting, and civil calendar calculations.

kolt
import std "datetime"
import std "io"

const now = datetime.now()
io.println(now.toIsoString()) // 2026-09-20T17:30:00.000Z
io.println(now.format("YYYY-MM-DD HH:mm:ss")) // 2026-09-20 17:30:00

const parsed = try datetime.parse("2026-09-20T15:30:00.000+02:00")
const tomorrow = parsed.addDays(1)

DateTime methods ​

toEpochMillis(): int ​

kolt
const dt = datetime.now()
io.println(dt.toEpochMillis())

Converts the calendar moment to milliseconds since UNIX epoch (1970-01-01T00:00:00Z).

toEpochSeconds(): int ​

kolt
const dt = datetime.now()
io.println(dt.toEpochSeconds())

Converts the calendar moment to seconds since UNIX epoch.

toIsoString(): string ​

kolt
const dt = datetime.now()
io.println(dt.toIsoString()) // 2026-09-22T14:30:00.000Z

Formats the moment as a standard ISO 8601 string representation.

format(pattern: string): string ​

kolt
const dt = datetime.now()
io.println(dt.format("YYYY-MM-DD HH:mm:ss"))

Formats the date by substituting pattern tokens: YYYY, YY, MM, DD, HH, mm, ss, and SSS.

addDays(days: int): DateTime ​

kolt
const tomorrow = datetime.now().addDays(1)

Returns a new DateTime instance shifted by days.

addHours(hours: int): DateTime ​

kolt
const later = datetime.now().addHours(2)

Returns a new DateTime instance shifted by hours.

addMinutes(minutes: int): DateTime ​

kolt
const soon = datetime.now().addMinutes(15)

Returns a new DateTime instance shifted by minutes.

addSeconds(seconds: int): DateTime ​

kolt
const next = datetime.now().addSeconds(30)

Returns a new DateTime instance shifted by seconds.

addMillis(millis: int): DateTime ​

kolt
const exact = datetime.now().addMillis(500)

Returns a new DateTime instance shifted by millis.

DateTime fields ​

DateTime instances expose individual calendar components:

  • year: int: Full 4-digit calendar year
  • month: int: 1 to 12
  • day: int: 1 to 31
  • hour: int: 0 to 23
  • minute: int: 0 to 59
  • second: int: 0 to 59
  • millisecond: int: 0 to 999
  • timezoneOffsetMinutes: int: Minutes east of UTC (e.g. +120 for UTC+2)

Standalone Functions ​

Returns the current system date and time. Defaults to UTC unless local = true is supplied.
