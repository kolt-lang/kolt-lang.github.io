Writing Native Extensions

Language Server (LSP)

On this page

std ffi ​

FFI has two gears. Registered extensions expose Kolt native functions, while dynamic libraries exist for calling arbitrary C symbols through tags.

kolt
import std "ffi"
import std "io"

try ffi.load("./libext.so")

const libc = try ffi.open("libc.so.6")
const v = try libc.call("abs", ffi.I32, [ffi.I32], -42)
const absFn = libc.func("abs", ffi.I32, [ffi.I32])
io.println(try absFn(-100))

const h: ffi.Handle = try ffi.call("get_ptr", ffi.KoltFFIPointer)
io.println(h.readI32(0))

Type tags ​

kolt
// every C ABI kind has a tag const
const i = ffi.I32 // int kinds: I8, U8, I16, U16, I32, U32, I64, U64, Size, SSize
const f = ffi.F64 // float kinds: F32, F64
const b = ffi.Bool // bool kind
const v = ffi.Void // null kind, for no return value
const p = ffi.Pointer // Handle kind, for void*
const s = ffi.CString // string | null kind, for const char*
const tag: ffi.FFITag<int> = ffi.I32 // each const carries its Kolt type

DynamicLibrary methods ​

call<T>(functionName: string, returnType: FFITag<T>, paramTypes: array<FFITag>, ...args): T! ​

kolt
const v = try libc.call("abs", ffi.I32, [ffi.I32], -42)

Throws when the symbol is missing, the arg count mismatches, or an arg cannot convert. Handle args unbox automatically, pointer results wrap back into Handle.

func<T>(functionName: string, returnType: FFITag<T>, paramTypes: array<FFITag>) ​

kolt
const absFn = libc.func("abs", ffi.I32, [ffi.I32])
io.println(try absFn(-100))

Reusable typed closure over one C symbol.

Standalone functions ​

load(path: string): null! ​

kolt
try ffi.load("./libext.so")

Requires kolt_extension_init in the library. Throws when the file cannot open or the symbol is missing.

open(path: string): DynamicLibrary! ​

kolt
const libc = try ffi.open("libc.so.6")

call<T>(name: string, returnType: KoltFFITag<T>, ...args: any): T! ​

kolt
const res = try ffi.call("my_native", ffi.KoltFFIInt, 1, 2)

Calls a registered extension function by name. The C header for authors ships at extensions/kolt.h, with examples in examples/. Return tags: KoltFFIInt, KoltFFIFloat, KoltFFIString, KoltFFIBuffer, KoltFFIBool, KoltFFIPointer, KoltFFIAny, KoltFFIVoid, KoltFFIArray, KoltFFITuple, KoltFFIMap, KoltFFINumber, KoltFFIBigInt, KoltFFIFunction.
