std math ​

Float math plus constants. Everything here is float, for ints prefer the native int and float methods.

kolt
import std "math"
import std "io"

io.println(math.sin(math.PI / 2)) // 1.0
io.println(math.pow(2.0, 10.0)) // 1024.0
io.println(math.hypot(3.0, 4.0)) // 5.0

Constants ​

INF: float, NAN: float, PI: float, E: float, TAU: float. All come from intrinsics.

kolt
io.println(math.PI)
io.println(math.TAU) // 2 * PI
