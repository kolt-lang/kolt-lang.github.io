Native Methods ​

These ship with the runtime, so there is nothing to import. Calls go directly on the value itself. Dispatch is by concrete type, which means int and float have their own sets and there is no runtime number case. The number stub only exists so number annotated code still checks.

string ​

Strings are immutable, every transform returns a fresh one.

length(): int ​

kolt
import std "io"

io.println("hi".length()) // 2

kolt

kolt

kolt

indexOf(part: string): int! ​

kolt

Only single chars are accepted, longer strings throw, a miss just gives -1.

map K V ​

Bracket access is sugar here. m["k"] reads with null on miss, m["k"] = v writes.

get(key: K): V | null ​

kolt
const m = {a: 1}
io.println(m.get("a")) // 1
io.println(m.get("missing")) // null

set(key: K, value: V): null ​

kolt
const m = {
}
m.set("a", 1)
io.println(m["a"]) // 1

kolt
