CLI Reference ​

The kolt CLI provides a unified toolchain for developing, testing, compiling, and packaging Kolt applications.

bash
# Common commands
kolt run src/main.kolt              # Run source or .kbc file
kolt check src/main.kolt            # Typecheck without running
kolt build src/main.kolt            # Compile to bytecode
kolt pack src/main.kolt myapp       # Build standalone executable
kolt fmt src/main.kolt              # Format source in place
kolt fix src/main.kolt              # Auto-insert missing try keywords
kolt test                           # Run manifest test script

Global Options ​

The following flags are supported across runtime and development commands:

FlagShortDescription
--no-warnings-wSuppresses compiler, deprecation, and runtime warnings
--time-tPrints a pipeline breakdown: Resolve, Parse, Typecheck, Optimize, Compile, VM Run
--watchWatches project source files and automatically re-runs on changes
--no-typesBypasses type analysis for fast iteration during prototyping

Commands ​

kolt run ​

Executes Kolt source files (.kolt) or precompiled bytecode (.kbc).

bash
kolt run src/main.kolt
kolt run src/main.kolt -- arg1 arg2
kolt run --watch src/main.kolt
kolt run -t src/main.kolt
  • Additional arguments after the script or after -- are passed to process.args.

kolt -e, --eval ​

Evaluates a Kolt code string directly from the terminal.

bash
kolt -e 'io.println("Hello, Kolt!")'
kolt -e 'for i in 0..5 { io.println(i) }'
  • In error reports, evaluated code is identified with the source location <eval>.
  • Supports -w and -t flags.

kolt check ​

Performs lexical analysis, parsing, type checking and compiling without running the bytecode or VM.

bash
kolt check src/main.kolt
kolt check --no-compile src/main.kolt
  • Verifies module imports, type annotations, generics, and throw contracts.
  • Exits with code 0 on success: Success Verified N files (0 errors).
  • Defaults to package.entry from kolt.toml when no file is passed.

kolt build ​

Compiles Kolt source code into a standalone .kbc bytecode file.

bash
kolt build src/main.kolt
kolt build src/main.kolt -o dist/app.kbc
kolt build --obfuscate src/main.kolt

Output Resolution ​

The destination path is resolved in this order:

  1. Explicit -o, --output <path> flag.
  2. package.output setting in kolt.toml.
  3. Default path ./dist/output.kbc.

Parent directories are created automatically if they do not exist.

Options ​

  • -o, --output <path>: Specifies destination .kbc file path.
  • --obfuscate: Obfuscates identifier and symbol names in bytecode string pools.

kolt pack ​

Packages a Kolt application into a standalone executable binary containing the Kolt virtual machine runtime.

bash
kolt pack
kolt pack src/main.kolt
kolt pack src/main.kolt build/myapp
kolt pack --no-obfuscate

Resolution ​

  • Entry file: Uses the specified file, or defaults to package.entry from kolt.toml.
  • Output binary: Uses the specified output path, or defaults to package.name from kolt.toml (<name>.exe on Windows), falling back to output_app (output_app.exe on Windows). Parent directories are created automatically if needed.

Options ​

  • By default, chunk symbols are obfuscated for minimal binary size. Use --no-obfuscate to preserve symbol names for stack traces.
  • Bundles native dynamic libraries configured under build.embed_libraries in kolt.toml.

kolt fmt ​

Formats Kolt source code in place using the built-in AST formatter.

bash
kolt fmt src/main.kolt
  • Enforces consistent indentation, spacing, and AST structure.
  • If a file contains syntax errors, formatting is safely skipped without altering the file.

kolt fix ​

Analyzes static throw contracts and automatically inserts missing try keywords where unhandled errors can occur.

bash
kolt fix
kolt fix src/main.kolt
  • Defaults to package.entry from kolt.toml when no file is passed.
  • Reports the number of insertions performed across analyzed files.

kolt dump ​

Disassembles and displays human-readable virtual machine bytecode instructions for a .kolt source or .kbc file.

bash
kolt dump src/main.kolt
kolt dump dist/output.kbc
  • Prints register allocations, constant pools, and instruction opcodes.
  • Useful for debugging JIT hot paths and compiler optimizations.

kolt repl ​

Starts an interactive Read-Eval-Print Loop session.

bash
kolt repl
  • Retains variables, classes, and function definitions across inputs.
  • Expressions print formatted results with syntax highlighting.
  • Exit with exit, Ctrl+D, or Ctrl+C.

kolt init ​

Scaffolds a new Kolt project structure with standard configuration.

bash
kolt init my_project
kolt init --no-git my_project

Creates:

  • kolt.toml: Project manifest.
  • src/main.kolt: Starter entry point.
  • dist/: Build output directory.
  • .gitignore: Git configuration (unless --no-git is specified).

kolt -v, --version ​

Displays the installed Kolt compiler, VM, and bytecode specification versions.

Project Scripts (kolt <script>) ​

When you run kolt <name>, Kolt searches kolt.toml for a matching command under [scripts]:

toml
[scripts]
test = "kolt run tests/index.kolt"
start = "kolt run src/server.kolt"

Running:

bash
kolt test

Echoes and executes the configured command string. Additional arguments passed on the command line are appended to the script command.
