On this page

Types and Variables ​

JavaScript or Kotlin habits transfer directly. Values are always concrete int or float; number only exists in annotations.

Comments ​

Line comments ​

kolt
// this is a line comment
let x = 1 // trailing comment works too

Block comments ​

kolt
/* block comment, and yes /* they nest */ properly */
// skipped normally, collected for docs and formatting

Semicolons and newlines ​

Optional semicolons ​

kolt
let x = 1   // semicolon is optional
let y = 2;

Leading operator gotcha ​

kolt
let x = 1
  // + 2 // syntax error: a leading operator never continues the line
let y = 1 +
  2 // fine, chaining operators belong at the end of the line
  // breaks on: + - * / % << & | += -= == != < <= > >= and or ??

Exempt keywords ​

kolt
let r = val
  is string // is, in, catch, as, ? keep parsing across newlines

Literals ​

int ​

kolt
let a: int = 42
let h: int = 0xFF // hex works too
// too big for i64 becomes BigInt

float ​

kolt
let f: float = 0.5
let s: float = 1e5 // scientific notation

bigint ​

kolt
let b: bigint = 123n
let hb: bigint = 0xFFn

strings ​

kolt
let d: string = "hi"
let q: string = 'it\'s' // single quotes behave the same
// only \n \r \t \e \" \' \\ are real escapes, the rest stays literal
// no 1_000 separators, no 0b or 0o, no char literal

Interpolation ​

kolt
// ${...} with balanced braces
let t: string = `x=${x + 1}`

bool and null ​

kolt
let ok: bool = true
let n = null

Arrays and maps ​

kolt
let arr = [1, 2]
let m = {"k": 1}

Tuples ​

kolt
// always immutable
let tup = (1, "a")
let unit = ()
let one = (x,) // trailing comma makes it a one element tuple, (x) is just parens

Buffers ​

kolt
// no buffer literal, @buffer or @embedBytes instead
let buf = @buffer([1, 2, 3])
buf = @buffer("Hi")

Number math ​

int stays int ​

kolt
io.println(7 / 2) // 3, division truncates

float takes over ​

kolt
// int widens to float automatically, float never shrinks back
io.println(7.0 / 2) // 3.5, any float in the mix makes the result float

let, const, destructuring ​

let is mutable ​

kolt
let x: int = 1
x = 2

const is locked ​

kolt
// the lock covers fields too
const y = 3
// y = 4 // error: cannot reassign a constant

Destructuring ​

kolt
let (a, b) = (1, 2)

Typed destructuring ​

kolt
const (c, d): (int, int) = (3, 4)

Nested patterns ​

kolt
// top level destructured names can be exported
let ((p, q), r) = ((1, 2), 3)

Type annotations ​

number supertype ​

kolt
let n: number = 1 // accepts int or float
// runtime is/as checks: number matches either Int or Float

Unions ​

kolt
let u: string | int = "x"

Nullable shorthand ​

kolt
let qq: string? = null // same as string | null

Arrays ​

kolt
let arr2: array<int> = [1]
let bare: array = [] // same as array<any>

Maps ​

kolt
let mm: map<string, int> = {}
let mm3: map = {} // same as map<string, any>

Tuple types ​

kolt
let tt: (int, string) = (1, "a")

Function types ​

kolt
let cb: fn(a: int): string = (a) => ""

Class objects ​

kolt
let cls: class<Animal> = Animal // the class itself, not an instance
// anything else names an instance type: Point, Box<int>, foo.Bar<T>

Tasks ​

kolt
let tsk: task<int> = spawn foo()

Generics ​

Generic functions ​

kolt
fn id<T>(x: T): T {
  return x;
}

Bounded generics ​

kolt
// : and extends both work for bounds
fn clamp<T: number>(x: T, lo: T, hi: T): T {
  return x;
}
fn shape<T extends Shape>(s: T): float {
  return s.area();
}

Generic classes ​

kolt
class Box<T> {
  let value: T
  fn init(v: T) {
    this.value = v;
  }
}
class NumBox<T: number> {
  let v: T
  fn init(x: T) {
    this.v = x;
  }
}
class Sub extends Base<int> {
}

Call site type args ​

kolt
// only when <...> sits directly before (, otherwise a comparison
// Instance matches any class instance, Enum any enum definition, fn any function
let y = id<int>(5)
obj.method<string>("hi")

Operators ​

Loosest to tightest, all left associative:

  1. += -=
  2. catch ?? ? : as
  3. or
  4. and
  5. == !=
  6. < <= > >= is is not in
  7. + - << & |
  8. * / %

Compound assign ​

kolt
// same deal as ++: variables, fields, and indexed elements all work
x += 5
x -= 2
instance.field += 5
arr[0] -= 2

Ternary ​

kolt
let t2 = cond ? 1 : 2

Nullish and catch ​

kolt
// catch needs a fallback value after the optional error name
let s2 = a ?? b catch "d"

Shifts ​

kolt
let sh = a << 2
let rs = a >> 1

Increment ​

kolt
i++

Decrement ​

kolt
i--

On fields and elements ​

kolt
// no prefix form, always after the target
instance.field++
arr[0]++
instance.field--

Mixed example ​

kolt
// no && || ^ ~, logic is and or plus !expr
// => lives in match, .. in ranges, ... in variadics and spread, @ in directives
let r = 1 + 2 * 3 & 6 | 1

Checks, casts, membership, safe navigation ​

is narrowing ​

kolt
if x is string {
  io.println(x.length());
}

is not narrowing ​

kolt
// single token, whitespace between the words is required
if x is not null {
  io.println(x);
}

Class checks ​

kolt
if p is Cat {
  p.meow();
}

Hard cast ​

kolt
let s3 = v as string // dies with a cast error on mismatch

Safe cast ​

kolt
// null on mismatch instead of dying
// members on any stay hidden until is narrowing or as casting
let qq2 = v as? string

Membership in maps ​

kolt
// key check on maps, value check on arrays, nothing else
if "k" in myMap {
  io.println("found");
}

Membership in arrays ​

kolt
if 1 in [1, 2] {
  io.println("found");
}

in only works on maps (key check) and arrays (value check).

Safe field access ​

kolt
let nm = user?.name // null when user is null

Safe index ​

kolt
let vv = arr?.[0]

Safe call ​

kolt
let rr = obj?.method(1, 2)

An Error value is not Null, so it passes through to the real operation instead of short circuiting.

Runtime type name ​

kolt
let tn = @typeOf(x) // "int", "float", "string", never "number"

Naming and visibility ​

Exported function ​

kolt
export fn pubFn(): int {
  return 1;
}

Exported variable ​

kolt
export let version = 1

Re-exported import ​

kolt
export import "./helper"

A file with at least one top level export becomes strict about what outsiders can use. Files without any export stay open. private only exists inside class bodies, for fields and methods. Camel case violations produce a friendly warning, redefining the same name in one scope is an error.
