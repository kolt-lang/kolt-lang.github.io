Concurrency ​

Spawned functions run on a pool of worker threads sharing one heap.

Spawning ​

Spawn a function call ​

kolt
fn calculatePrimes(limit: int): array<int> {
  let primes = []
  for n in 2..limit {
    let isPrime = true
    for d in 2..n {
      if d * d > n { break }
      if n % d == 0 {
        isPrime = false
        break
      }
    }
    if isPrime {
      primes.push(n)
    }
  }
  return primes
}

// Runs calculatePrimes concurrently on a worker thread
let task = spawn calculatePrimes(1000)

Spawn an anonymous arrow ​

kolt
// Directly spawn an arrow with a full multiline block body
let task = spawn () => {
  let sum = 0
  for i in 1..10000 {
    sum += i
  }
  return sum
}

Spawn a stored function ​

kolt
let processBatch = (items: array<string>) => {
  let processed = []
  for item in items {
    processed.push(item.toUpperCase())
  }
  return processed
}

// Arguments and results cross threads as handles on the shared heap
let task = spawn processBatch(["apple", "banana", "cherry"])

Awaiting ​

Single task ​

kolt
let result = await task
let cached = await task // subsequent awaits retrieve the stored outcome

Task array join ​

kolt
let t1 = spawn calculatePrimes(500)
let t2 = spawn calculatePrimes(1000)

// Awaits both tasks sequentially and returns their results in order
let results = await [t1, t2]

Cancellation ​

Cancel a task ​

kolt
task.cancel()

Check status ​

kolt
task.isDone()
task.isCancelled()

Awaiting a cancelled task ​

kolt
task.cancel()
const r = await task // Error("Task was cancelled")

Shared heap visibility ​

kolt
const items = []
const task = spawn () => {
  for i in 0..5 {
    items.push(i * 10)
  }
}
await task
io.println(items) // [0, 10, 20, 30, 40], mutations are visible across threads

Coordination ​

Mutex with lock helper ​

kolt
import std "sync"

const counter = sync.Mutex(0)

// withLock executes the callback while holding the lock and releases it automatically
counter.withLock((count) => {
  io.println(`Current count: ${count}`)
})

Manual lock and unlock ​

kolt
// Manual locking for custom control flow
const guard = counter.lock()
counter.unlock(guard)

Blocking queue ​

kolt
const queue = sync.Queue<string>()
queue.push("event")
let item = queue.pop() // blocks until an item is available

Non-blocking pop ​

kolt
let item: string? = queue.tryPop() // returns null if empty

Debugging Hooks ​

bash
KOLT_NO_JIT=1 kolt run app.kolt # skip the JIT entirely
KOLT_TRACE=1 kolt run app.kolt # trace every call
KOLT_JIT_TRACE=1 kolt run app.kolt # trace JIT regions only
