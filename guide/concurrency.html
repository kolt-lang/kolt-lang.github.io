On this page

Concurrency ​

Spawned functions run on a pool of worker threads sharing one heap.

Spawning ​

Spawn a named function ​

kolt
let t = spawn worker()

Spawn an arrow ​

kolt
let t2 = spawn (() => 42)

Spawn a stored function ​

kolt
let work = () => 7
// args and results cross threads as plain handles, nothing copied
let t3 = spawn work

Awaiting ​

Single task ​

kolt
let r = await t
let r2 = await t // same result again, tasks remember their outcome

Task array join ​

kolt
let rs = await [t1, t2] // fresh array of results, in order
let mixed = await [t1, 99] // non tasks pass through untouched

Cancellation ​

Cancel a task ​

kolt
t.cancel()

Check completion ​

kolt
t.isDone()

Check cancellation ​

kolt
t.isCancelled()

Awaiting a cancelled task ​

kolt
t.cancel()
const r = await t // Error("Task was cancelled"), the work never lands
// long tasks pause roughly every 10ms, so none hogs a thread

Shared memory stays visible ​

kolt
const seen = []
const t = spawn (() => seen.push(1))
await t
io.println(seen) // [1], writes before await are seen after it

Coordination ​

Mutex with lock helper ​

kolt
import std "sync"

const m = sync.Mutex(0)
m.withLock((x) => io.println(x))

Manual lock dance ​

kolt
// escape hatch only: throwing between lock and unlock leaks the lock,
// withLock above does not
const v = m.lock()
m.unlock(v)

Blocking queue ​

kolt
const q = sync.Queue<int>()
q.push(1)
let x = q.pop() // blocks until an item arrives

Non blocking pop ​

kolt
let y: int? = q.tryPop() // null when empty

Debugging Hooks ​

bash
KOLT_NO_JIT=1 kolt run app.kolt # skip the JIT entirely
KOLT_TRACE=1 kolt run app.kolt # trace every call
KOLT_JIT_TRACE=1 kolt run app.kolt # trace JIT regions only
