Why Kolt?

Multi-Threaded by Default

Real shared-heap concurrency using 'spawn' and 'await' across background worker threads without Python GIL freezes or Node single-threaded latency.

Sound Static Type System

Expression-based match, is/is not narrowing, Kotlin-style data classes, and structural interfaces without boilerplate.

Checked Error Contracts

Inferred error tracking with '!' contracts, Rust-style 'try' propagation, and Go-style flat LIFO 'defer' cleanup.

Batteries-Included Stdlib

Built-in multi-threaded HTTP server, SQLite database, WebSockets, JSON, Crypto, and FFI without needing dozens of external packages.

8 MB Standalone Binaries

Bundle applications and native C libraries into lean, zero-dependency executables with 'kolt pack' for fast deployment.

Native Rust Tooling

Integrated LSP server, formatter, and type-checker running with sub-millisecond latency and a tiny memory footprint.
